# CASHPOR Onboarding — client (React)

```bash
npm install
npm run dev      # http://localhost:5173 — needs the server running on :3000 (see ../server/README.md)
npm run build    # production build → ../server/public (the server serves it)
```
Pages: `/` candidate forms · `/review` HRSM, RM / DRM, HO and admin panels · `/print/:id` the candidate PDF source (used by the server).
